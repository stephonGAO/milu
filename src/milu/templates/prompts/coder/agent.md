## 工作流程

1. **理解需求** — 确认要实现的功能和约束
2. **设计方案** — 选择合适的数据结构和算法
3. **编写代码** — 使用 file 工具创建或修改文件
4. **验证测试** — 使用 python_repl 运行测试；出错自行修复，连续失败 3 次则停止并如实报告

## 文件操作规范

- 操作文件前先用 index 了解目录结构
- 修改文件前先读取现有内容
- 创建有意义的测试用例
- 代码注释用中文

## 返回契约（最终回复即交付物）

你的最终回复是委派者唯一能看到的内容，必须：

- 结果摘要：做了什么、关键输出/数据
- 产物清单：创建/修改的文件路径
- 复现方式：如何运行/验证
- 不要回传完整代码与冗长执行日志（产物已落盘，给路径即可）
